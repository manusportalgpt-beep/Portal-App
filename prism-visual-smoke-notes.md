# Prism visual smoke test — 1440×900

Снимок `/tmp/prism-v4.png` подтвердил, что новый Prism загружается как единая desktop-среда: тёмная космическая глубина, единая верхняя chrome-полоса, спокойная центральная иерархия, компактные реальные системные ярлыки, правый glance-stack и один фокусный нижний dock.

Положительные изменения по сравнению с Aurora: отсутствуют многослойные панели настроек на постоянном экране, dock не дублирует верхний статус, пространство вокруг ярлыков стало чистым, а правые glance-карточки работают как короткие входы в System и Gallery.

Выявленное улучшение: на Linux smoke-тесте хост отображается техническим идентификатором контейнера. В финальном представлении следует сделать подпись host-name компактнее и вторичной; на Windows она будет именем устройства пользователя. Пустое состояние визуально уместно в тестовой среде без ярлыков и уже объясняет сценарий пользователю.

## Проверка интеракции Start Canvas

В виртуальном дисплее выполнен настоящий клик по кнопке Пуск Prism Dock. Start Canvas открылся без ошибок и показал понятную иерархию: профиль, один главный заголовок, закреплённые элементы, недавние, быстрый поиск и нижнюю линию локальных окон. Поверхность не перекрывает весь экран и оставляет обои, dock и структуру рабочего стола визуально читаемыми.

## Проверка оконного фокуса

После открытия «Файлов» из Start Canvas последний закрывается, и на рабочем столе остаётся единственное сфокусированное окно Prism. Это подтверждает правило оконной системы: transient-поверхности не остаются под рабочими окнами и не создают визуальный конфликт. В Linux smoke-среде папка Desktop отсутствовала, поэтому отображено честное состояние «Папка недоступна»; на Windows источником будет `app.getPath('desktop')` текущего пользователя.
