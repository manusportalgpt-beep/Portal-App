# Windows 12 Launcher — Aurora Desktop

**Aurora Desktop** — отдельная локальная оболочка Windows x64, построенная вокруг реального рабочего стола пользователя. Это не замена `explorer.exe`: приложение не меняет системные файлы, не устанавливает драйверы или службы и не вмешивается в запуск Windows.

## Версия 0.3.0

Версия 0.3.0 полностью заменяет перегруженную структуру прежнего прототипа. На постоянном экране остаются только обои, настоящие ярлыки и один Aurora Dock. Меню Пуск, Control Center и персонализация открываются только по действию пользователя, поэтому элементы не дублируются и не конкурируют за внимание.

| Возможность | Как реализовано |
|---|---|
| Реальные приложения | Сканируются `.lnk`, `.url` и `.exe` с Desktop и из пользовательского/общего Windows Start Menu. |
| Настоящие значки | Для найденного элемента используется `app.getFileIcon()` и в UI передаётся безопасный data URL; при неудаче применяется единый fallback-значок. |
| Безопасный запуск | UI запускает только ID из локального каталога. Произвольные команды и пути из renderer не выполняются. |
| Aurora Dock | Пуск, поиск, закреплённые элементы, статус; drag-and-drop меняет порядок и сохраняет его локально. |
| Start Home | Поиск, запуск по Enter, реальные приложения и быстрый доступ к системным папкам. |
| Control Center | Фокус, видимость ярлыков, атмосфера, выбор обоев, тема и затемнение фона. |
| Персонализация | Отдельные компактные вкладки «Внешний вид», «Рабочий стол», «Dock» и «Язык». |
| Темы | Полярный фиолетовый, Северный океан и Красная ночь. |
| Локальные данные | Настройки, закрепления и выбранные обои хранятся только в Electron `userData`. |

## Конфиденциальность

Интерфейс не выполняет сетевые запросы: CSP запрещает `connect-src`, а Electron использует `contextIsolation`, `sandbox` и отключённый Node.js в renderer. Доступ к файловой системе ограничен главным процессом и требуется только для поиска разрешённых ярлыков, системных папок, локальных значков и явно выбранных пользователем обоев.

## Запуск

Скачайте `Windows12-Launcher-0.3.0-x64.exe` и откройте файл в Windows 10/11 x64. Это portable-сборка — установка не требуется. SmartScreen может запросить подтверждение, поскольку portable exe не имеет коммерческой подписи.

## Разработка и сборка

```bash
npm install
npm start
npm run build:win
```

Готовый файл появится в `release/Windows12-Launcher-0.3.0-x64.exe`. Нативная сборка Windows x64 выполняется также через `.github/workflows/windows-build.yml`.

## Ограничение

Приложение работает как отдельный безопасный launcher, а не как shell replacement. Для замены Explorer понадобились бы отдельные сценарии восстановления системного shell, автозапуск, управление окнами и длительное тестирование на Windows.
