# Windows 12 Prism

**Windows 12 Prism** — отдельная локальная desktop-среда для Windows x64, вдохновлённая привычной логикой Windows 11 и современными desktop-сценариями. Это не подмена `explorer.exe`: приложение работает в собственном окне, не устанавливает драйверы или службы и не меняет системные файлы Windows.

## Что нового в 0.4.0

Prism заменяет набор разрозненных панелей цельным сценарием: на рабочем столе остаются обои, реальные ярлыки и один dock; поиск, управление, уведомления и настройки появляются только тогда, когда нужны.

| Возможность | Реальное поведение |
|---|---|
| Настоящие приложения | Читаются `.lnk`, `.url` и `.exe` с Desktop и из пользовательского/общего Windows Start Menu. |
| Системные иконки | Для ярлыков используется `app.getFileIcon()` с передачей изображения в renderer как data URL; fallback нужен только если ОС не вернула значок. |
| Command Palette | `Ctrl+K` открывает поиск приложений, папок и локальных действий; `Enter` выполняет выбранный результат. |
| Start Canvas | Закреплённые элементы, недавние запуски, быстрый поиск и переходы к локальным окнам. |
| Prism Dock | Перетаскиваемые закрепления, индикаторы, магнификация hover, открытые локальные окна, status и быстрые действия. |
| Control Island | Режим фокуса, кино-режим, видимость ярлыков, выбор обоев, палитра и яркость фона. |
| Prism Studio | Четыре компактные вкладки: внешний вид, рабочий стол, dock и взаимодействие; в том числе Русский / English. |
| Локальные окна | Файлы, Галерея, Заметки и О системе; окна можно перемещать, изменять размер, сворачивать, закрывать и снова открывать из dock. |
| Файлы и Галерея | Используются только разрешённые локальные папки: Desktop, Documents, Downloads и Pictures. Открытие файла выполняется по внутреннему ID. |
| Заметки | Хранятся исключительно в `notes.json` внутри Electron `userData`; автосохранение остаётся локальным. |
| Уведомления | Локальная история открытых действий и состояний без облачного сервиса. |
| Приватность | Сетевые соединения интерфейса заблокированы CSP; renderer изолирован, sandbox включён, Node.js отключён. |

## Управление

| Действие | Способ |
|---|---|
| Открыть Пуск | Кнопка Prism слева в dock |
| Быстрый поиск | `Ctrl+K` или кнопка поиска |
| Новая заметка | `Ctrl+N` |
| Закрыть временную поверхность | `Esc` |
| Переместить окно Prism | Потянуть за его верхнюю строку |
| Изменить размер окна | Потянуть за правый нижний угол |
| Закрепить приложение | Контекстное меню ярлыка или dock |

## Локальная безопасность

Renderer не получает произвольные пути для запуска или чтения. Главный процесс создаёт ограниченный каталог ярлыков и файлов, а команды `open` и `reveal` принимают только заранее известные ID. Для локальных папок возвращаются названия, метаданные, data URL иконок или миниатюр — абсолютные пути не передаются в UI.

> В Prism нет телеметрии, облачной синхронизации, фоновых API-запросов или скрытой отправки заметок и файлов.

## Запуск

Скачайте `Windows12-Launcher-0.4.0-x64.exe` и запустите на Windows 10/11 x64. Это portable-приложение — отдельная установка не нужна. Сборка содержит фирменную многоразмерную иконку Prism вместо стандартного значка Electron.

## Разработка и сборка

```bash
npm install
npm start
npm run build:win
```

Готовый файл появится в `release/Windows12-Launcher-0.4.0-x64.exe`. Нативная сборка Windows x64 дополнительно выполняется через `.github/workflows/windows-build.yml`.

## Ограничение

Windows 12 Prism — безопасный отдельный launcher, а не replacement системного shell. Полное замещение Explorer требовало бы самостоятельного набора механизмов восстановления shell, автозапуска, управления реальными окнами Windows и длительного тестирования на ПК.
