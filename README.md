# Windows 12 Launcher

**Windows 12 Launcher** — отдельная локальная оболочка для Windows x64, вдохновлённая Windows 11 и Seelen UI. Это не замена Windows Explorer и не системный модификатор: приложение открывается в собственном окне, не устанавливает драйверы, не создаёт службы и не изменяет системные файлы Windows.

## Что работает в версии 0.2.0

| Функция | Поведение |
|---|---|
| Реальные ярлыки рабочего стола | При запуске читаются `.lnk`, `.url` и `.exe` из Desktop текущего пользователя и публичного Desktop. |
| Каталог приложений | Меню Пуск ищет `.lnk`, `.url` и `.exe` в пользовательской и общей папках Windows Start Menu. |
| Запуск | Ярлык или папка открывается только по заранее найденному внутреннему ID. UI не передаёт произвольные команды или пути на запуск. |
| Системные папки | Доступны «Этот компьютер», «Рабочий стол», «Документы» и «Загрузки» через корректные пути Electron для текущего ПК. |
| Собственные значки | Для `.lnk` и `.exe` на Windows считывается системный значок; если получить его не удалось, отображается нейтральный fallback. |
| Dock | Реальные элементы можно запускать из dock; их порядок меняется перетаскиванием и сохраняется локально. |
| Обои | Можно выбрать PNG, JPG, JPEG, WEBP или BMP через системный диалог. Путь сохраняется только в локальном `userData`. |
| Виджеты | Локально отображаются время, имя компьютера, число CPU-ядер и использованная память. |
| Внешний вид | Темы: «Полярный фиолетовый», «Красная ночь», «Северный океан»; размеры ярлыков, видимость виджетов, auto-hide и стиль dock. |
| Язык | Русский по умолчанию, English доступен в настройках. |

## Конфиденциальность

Приложение **не использует телеметрию, облачную синхронизацию, сетевой API или скрытую отправку данных**. Рендерер работает с отключённым Node.js, `contextIsolation` и `sandbox`; между UI и Windows доступен только ограниченный IPC-мост.

> Обои и иконки могут загружаться только с локального диска после явного выбора пользователя или из найденных ярлыков Windows. Сетевые подключения в пользовательском интерфейсе запрещены CSP.

## Установка и запуск

Скачайте `Windows12-Launcher-0.2.0-x64.exe` и запустите его в Windows 10/11 x64. Это portable-сборка: отдельная установка не требуется. При первом запуске Windows SmartScreen может запросить подтверждение, поскольку exe не подписан коммерческим сертификатом.

## Разработка

```bash
npm install
npm start
```

## Сборка для Windows x64

```bash
npm run build:win
```

Файл появится в `release/Windows12-Launcher-0.2.0-x64.exe`. Для нативной сборки на Windows также доступен GitHub Actions workflow `.github/workflows/windows-build.yml`.

## Ограничения текущего релиза

Лаунчер намеренно не подменяет системный Explorer и не запускается как shell Windows. Он открывает разрешённые локальные ярлыки и папки в рамках обычного пользовательского сеанса. Для расширения до настоящей shell-replacement потребуется отдельный этап: протокол восстановления Explorer, управление автозапуском, список запущенных окон, drag-and-drop ярлыков на desktop и тщательное тестирование на Windows.
