# Windows 12 Launcher — Design System v3

## Концепция: Aurora Desktop

Цель — сделать рабочий стол настолько спокойным, чтобы обои и личные ярлыки пользователя оставались главными, но настолько выразительным, чтобы взаимодействия ощущались премиально. Оболочка не имитирует множество отдельных приложений; это один собранный desktop experience.

## Структура экрана

| Слой | Роль | Постоянно на экране |
|---|---|---|
| Обои | Личность рабочего пространства | Да |
| Ярлыки | Реальные программы и папки пользователя | Да, но только одна упорядоченная сетка слева |
| Aurora Dock | Пуск, поиск, закреплённые приложения, status hub | Да |
| Start Home | Поиск, избранное, список приложений и последние элементы | По действию пользователя |
| Control Center | Звук, сеть, темы, виджеты, обои, режим фокуса | По действию пользователя |
| Personalize | Расширенная настройка темы, фона, dock и поведения | Из Control Center |

## Исключение повторов

1. На рабочем столе нет постоянных часов: время находится только в status hub dock.
2. Нет верхней панели: освобождается вертикальное пространство и не конкурирует с dock.
3. Нет второй панели «быстрых папок»: папки живут в Start Home и реальных ярлыках.
4. Нет отдельных кнопок «Пуск» в нескольких местах: одна узнаваемая кнопка в dock.
5. Нет системного статуса в нескольких виджетах: компактная status-зона раскрывается в Control Center.
6. Настройки не выводятся как множество вложенных тёмных карточек: используется одна canvas-страница с группами полей.

## Иконография

Реальные элементы Windows получают raster-значок через `app.getFileIcon()` и передаются в renderer как data URL. Это устраняет нестабильность `file://` при отображении `.ico` и `.exe`, а также не раскрывает файловые пути из главного процесса. Fallback использует одно семейство графических символов с одинаковой формой плитки, тенью и контрастом.

## Motion и взаимодействие

Dock использует мягкую магнификацию около курсора, активная программа отмечается точкой, а reorder выполняется drag-and-drop. Start Home открывается из нижней части dock без скачка размера. Control Center открывается от status hub и содержит только быстрые действия. Настройки открываются из Control Center, а не из многих отдельных кнопок.

## Минимальный набор заметных фишек

1. Динамическая магнификация dock.
2. Анимация входа ярлыков без задержки работы.
3. Поиск приложения с быстрым запуском Enter.
4. Пиннинг и reorder dock.
5. Нативные значки найденных Windows-приложений.
6. Режим фокуса: скрывает ярлыки и снижает яркость фона.
7. Управление затемнением обоев.
8. Control Center с темой, обоями, виджетами и фокусом.
9. Контекстная карточка обложки текущих обоев.
10. Быстрый перечень системных папок.
11. Честные состояния: если приложение не найдено — нет фиктивного запуска.
12. Клавиатурные shortcuts: Ctrl+K, Escape, Enter.
13. Уважение `reduce motion`.
14. Переключение RU/EN.
15. Хранение всех настроек локально.
