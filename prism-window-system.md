# Prism Window System

## Архитектура слоёв

1. **Wallpaper layer** — атмосфера, цвет, глубина и пользовательские обои. Никогда не содержит кнопок.
2. **Desktop layer** — реальные ярлыки Windows и небольшие контекстные меню.
3. **Dock layer** — один постоянный центр навигации, с магнификацией и открытыми локальными окнами.
4. **Transient layer** — Command Palette, Start Canvas, Control Island, Notification Stack. Только одна главная transient-поверхность одновременно.
5. **Window layer** — локальные представления Файлов, Галереи, Заметок и Системы. Каждое имеет focus, elevation и отдельный z-index.

## Окна

Окна Prism не выдают себя за системный Explorer. Это собственные безопасные представления лаунчера, работающие с ограниченными локальными источниками данных. В окне Файлы доступны только разрешённые «Рабочий стол», «Документы», «Загрузки» и «Изображения». Открытие конкретного файла выполняется главным процессом по ID из внутреннего каталога.

| Окно | Данные | Действия |
|---|---|---|
| Файлы | Разрешённые папки и их локальное содержимое | Открыть файл, перейти в папку, открыть расположение |
| Галерея | Изображения из Pictures | Сетка превью, увеличить, открыть оригинал |
| Заметки | `notes.json` в Electron userData | Создать, редактировать, удалить, автосохранение |
| Система | Только локальные общие метрики OS | Просмотр CPU, RAM, хоста, диска и версии |

## Состояние и управление

Окно получает `windowId`, положение, размер, фокус и `minimized`. Перетаскивание разрешается только за header; resize используется через нижний угол. Maximize не требуется для первого релиза: сфокусированное окно визуально поднимается, а фон слегка размывается только при открытии transient-панелей.

## Визуальный язык

Окна Prism используют полупрозрачный материал с внутренним светом, но не каждый внутренний блок становится отдельной карточкой. Внутри окна есть лишь canvas, тонкий разделитель и один активный акцент. Отдельный уровень глубины строится через shadow, saturation и subtle scale, а не через тяжёлые рамки.

## Безопасность

Renderer не получает абсолютные пути. Главный процесс создаёт временные безопасные IDs для элементов, возвращает имя, тип, время, размер и data URL миниатюры/иконки. Команды `open` и `reveal` принимают только известные IDs. Заметки сохраняются в userData и не отправляются по сети.
