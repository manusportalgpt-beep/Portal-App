# Визуальные критерии переработки рабочего стола

## Референс пользователя

Нужен настоящий рабочий стол, а не центральный dashboard: обои занимают весь экран, ярлыки размещены вертикальными колонками по левому и правому краям, снизу находится узкая системная панель задач с кнопкой Windows, закреплёнными приложениями и областью уведомлений. Главное содержимое рабочего стола не должно перекрывать фон постоянно.

## Windows 11

Официальная документация Microsoft описывает панель задач как центральный элемент для запуска приложений, переключения окон и доступа к системным функциям, включая меню Пуск, поиск и область уведомлений. В Windows 11 важны закреплённые приложения, настройка выравнивания значков и управление системными значками трея.

Источник: https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows

## Seelen UI

Официальный сайт Seelen UI позиционирует продукт как полноценную замену desktop environment, а не просто тему. Ключевые элементы: настраиваемый dock/taskbar, рабочие пространства, tiling window manager, media module, launcher в стиле Rofi, виджеты, темы и отдельная панель настроек. Поэтому новая версия должна быть desktop-first: фон и ярлыки являются базовым слоем, а launcher и настройки — временными стеклянными overlay-панелями.

Источник: https://seelen.io/

## Решение для новой версии

1. Убрать постоянный hero/dashboard из центра рабочего стола.
2. Добавить полноэкранный фон с тёмным изображением и настраиваемой прозрачностью overlay.
3. Отображать реальные локальные ярлыки Windows в двух колонках по краям, с выбором размера и расстояния.
4. Сделать нижнюю панель тонкой, стеклянной и постоянно доступной; добавить кнопку Пуск слева, центрированные закреплённые приложения и системный трей справа.
5. Меню Пуск открывать как компактное стеклянное окно поверх обоев, с поиском и закреплёнными приложениями.
6. Настройки сделать отдельным overlay-окном с вкладками: внешний вид, панель задач, рабочий стол, язык и конфиденциальность.
7. Добавить параметры: положение панели (низ/верх/лево/право), центрирование/левое выравнивание, автоскрытие, размер ярлыков, прозрачность, блюр, обои и темы.
8. Все действия, кроме явно выбранного открытия внешнего URL, должны работать локально и не собирать данные.
