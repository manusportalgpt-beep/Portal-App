# UX-аудит версии 0.2.0

## Наблюдения по экрану пользователя

Текущий desktop перегружен несколькими конкурирующими слоями: верхний toolbar, колонки ярлыков, стек виджетов, большой dock и открытые настройки. Каждый слой использует одинаковую тёмную полупрозрачную карточку, поэтому фокус размывается. Повторяются статус «Локально», часы, поиск, настройки, быстрые папки и визуальные акценты. Это создаёт впечатление конструктора панелей, а не целостной операционной оболочки.

Иконки также выглядят неоднородно: часть системных значков загружена, часть заменена одинаковыми fallback-плитками. Такое поведение нельзя считать готовым к релизу, особенно когда пользователь ожидает знакомую логику Windows.

## Принципы нового направления

| Проблема | Решение |
|---|---|
| Повтор статусов и быстрых действий | Один status hub в правой части dock; убрать локальный статус, часы и быстрые папки из остальных постоянных областей. |
| Слишком много стеклянных карточек | Glass используется только для временных поверхностей: Start, Command Center, Quick Settings и dock. Рабочий стол и иконки остаются лёгкими. |
| Большая форма настроек поверх рабочего стола | Компактный Command Center с боковой навигацией и одной активной страницей; без вложенных карточек-карточек. |
| Неровная иконография | Реальные raster-иконки Windows извлекаются через `app.getFileIcon()` в data URL; fallback-иконки принадлежат единому векторному семейству. |
| Сложный стартовый сценарий | Пуск сразу показывает поисковое поле, избранные элементы и компактный список последних/системных действий. |
| Dock выглядит как ещё одна панель | Единый центральный dock с крупными качественными иконками, увеличением при hover, индикаторами запуска и контекстным меню. |

## Вдохновение Windows 11

Microsoft формулирует четыре полезных направления для Start: приложения должны быть доступны с первого взгляда, меню нужно сделать персональным, каждый пиксель должен ускорять ежедневные действия, а знакомые иконки и мышечная память должны сохраняться. Поэтому новая оболочка использует узнаваемую модель рабочего стола Windows 11, но очищает её и усиливает аккуратным Liquid Glass.

Источник: https://microsoft.design/articles/start-fresh-redesigning-windows-start-menu/

## Визуальное решение

Рабочий стол получает спокойный фон с одной выразительной световой композицией, одной строкой ярлыков по левому краю или адаптивной сеткой, исчезающей при пустом пространстве. Верхняя полоса убирается целиком: управление переносится в dock и всплывающий command bar. В режиме без открытых панелей на экране остаются только обои, аккуратные ярлыки и один изящный dock.

Временные поверхности используют единый радиус, одну толщину обводки, одно направление света и три глубины elevation. Красный, фиолетовый или голубой акцент применяется только к активному контролу, фокусу и индикатору запуска, а не ко всем элементам одновременно.
