# Functional redesign: Windows 12 Launcher

## Причина неисправности

Предыдущая версия была визуальным прототипом: большая часть иконок не соответствовала реальным установленным программам и не имела исполняемых действий. Системные папки были описаны статически, а не получались через корректные Electron-пути Windows. Поэтому интерфейс выглядел как оболочка, но не выполнял главную функцию лаунчера.

## Безопасная функциональная модель

| Возможность | Реализация | Граница безопасности |
|---|---|---|
| Реальные ярлыки рабочего стола | Сканирование пользовательского и общего Desktop (`.lnk`, `.url`, `.exe`) | В интерфейс передаётся только каталог; запуск возможен только по ID элемента, заранее разрешённого главным процессом |
| Реальные приложения | Сканирование Start Menu текущего пользователя и общего Start Menu | Рекурсивное чтение каталогов с ограничением числа элементов; не исполняются найденные файлы автоматически |
| Открытие папок | Electron `app.getPath()` для desktop/documents/downloads/home | Только четыре именованные системные папки |
| Запуск элемента | `shell.openPath()` по пути из внутреннего каталога главного процесса | Интерфейс не передаёт произвольный путь для запуска |
| Персональные обои | Нативный выбор изображения через системный диалог | Допускаются только изображения; выбранный путь сохраняется локально в настройках |
| Локальное хранение | JSON внутри Electron `userData` | Нет телеметрии, облачной синхронизации и сетевого API |

## Визуальная модель

Новая версия должна стать полной desktop-first оболочкой, а не статическим макетом. Центральный слой — реальные обои пользователя. Прозрачный top bar показывает рабочий стол, активное пространство и локальный режим. Минималистичный стеклянный dock находится внизу и поддерживает масштабирование при наведении, drag-and-drop изменения порядка и компактные индикаторы запущенных/закреплённых элементов. Стартовое меню является command center: поле поиска в реальном каталоге приложений, избранные, последние открытые локальные папки и быстрые системные действия.

В дополнение к базовой логике Windows 11 берутся ориентиры Seelen UI: настраиваемый dock, toolbar со статусом системы, быстрый launcher, desktop widgets, управление обоями и прозрачные панели. Seelen UI заявляет эти элементы в составе полноценной среды Windows, включая автоскрываемый dock, живую status bar, launcher, системные widgets и визуальную настройку обоев.

Источник: https://seelen.io/apps/seelen-ui

## Основные интеракции

1. Один клик выделяет ярлык; двойной клик запускает реальный ярлык/папку.
2. Кнопка Пуск открывает каталог приложений, доступных на данном ПК, а поиск фильтрует именно этот каталог.
3. Приложение можно закрепить в dock; порядок закреплений меняется drag-and-drop и сохраняется локально.
4. В настройках можно выбрать собственные обои, степень затемнения, тему, видимость виджетов, размер ярлыков и режим dock.
5. Статус-виджет отображает процессор, RAM и время, получая сведения только из локальной ОС.
6. В интерфейсе больше нет фиктивного обещания запуска: если каталог программ недоступен, отображается ясное состояние и доступны системные папки.
