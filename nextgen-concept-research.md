# Исследование для Next-Gen Desktop

## Fluent Motion

Fluent 2 рекомендует связывать анимацию с понятным изменением состояния: elevation сообщает о глубине, drag-and-drop — об отношении элементов, а движение должно быть коротким, естественным, физически правдоподобным и ограниченным объектом в фокусе. В интерфейсе должен существовать режим без анимации.

Следствие для Windows 12 Launcher: окна получают реальную глубину и тень, перетаскиваемые элементы приподнимаются, анимируются только активные поверхности, а dock и панели не создают постоянного фонового движения.

Источник: https://fluent2.microsoft.design/motion

## Возможности Seelen UI

Seelen UI показывает, что ценность desktop-среды создают не декоративные панели, а системные сценарии: согласованная темизация, акцент, связанный с обоями, информационные виджеты на wallpaper layer и быстрый клавиатурный launcher. Актуальный репозиторий также отражает развитие dock, работы с закреплёнными задачами и локализации.

Следствие для Windows 12 Launcher: новая версия будет строиться вокруг одного системного dock, command palette, настоящих локальных окон-представлений, умных виджетов, быстрых действий и персонального акцента, без клонирования верхних тулбаров и дублей статуса.

Источник: https://github.com/eythaann/seelen-ui

## Концепция: Windows 12 Prism

Prism — это «живое пространство», а не набор карточек. На пустом рабочем столе видны только обои, реальные ярлыки и dock. По действию появляются притягивающие взгляд, но краткоживущие сущности:

| Сценарий | Новая поверхность |
|---|---|
| Запуск и поиск | Command Palette с быстрым поиском приложений, папок и действий |
| Пуск | Start Canvas с избранными, недавно открытыми и коллекциями |
| Системный статус | Control Island: громкость, режим фокуса, тема, фон и производительность |
| Уведомления | Notification Stack с таймлайном и очисткой |
| Локальные папки | Настоящие окна-представления: Файлы, Галерея, О системе, Заметки |
| Настройка | Prism Studio — один мастер-панель с live-preview |

### Первые реализуемые фишки

1. Command Palette: Ctrl+K, поиск с результатами и действиями.
2. Локальное окно «Файлы» с быстрыми папками, реальными файлами и открытием через Windows.
3. Локальное окно «Галерея» с миниатюрами изображений в Pictures.
4. Локальное окно «Заметки», сохраняемое только локально.
5. Локальное окно «О системе» с показателями CPU, RAM, именем хоста и диском.
6. Notification Stack: тосты превращаются в историю.
7. Контекстное меню ярлыка: открыть, закрепить в dock, показать расположение.
8. Акцент, вычисленный из выбранного фона, с ручным переопределением темой.
9. Режим кино: скрывает desktop icons и dock до движения мыши к нижнему краю.
10. Настраиваемые зоны dock: запуск, активные задачи, status island.
11. Живые превью и понятные inline настройки вместо многих больших экранов.
12. Клавиатурная навигация для всех основных поверхностей.
