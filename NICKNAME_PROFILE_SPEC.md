# Никнейм-ориентированный профиль Voxel

## Цель

Лаунчер должен восприниматься пользователем как запуск **основного Minecraft-ника**, а не как постоянный «вход через Microsoft». Для этого UI показывает фактический ник лицензионного Minecraft-профиля и использует сохранённую официальную сессию при каждом последующем запуске.

## Поведение

| Состояние | Отображение | Действие |
|---|---|---|
| Сессии нет | «Основной ник не подключён» | Кнопка «Подключить основной профиль» открывает единоразовое защищённое подтверждение в системном браузере. |
| Сессия есть | «Основной ник: `<имя>`» | Кнопка «Запустить как `<имя>`» устанавливает/проверяет Vanilla и запускает игру без нового браузерного входа. |
| Сессия истекла | «Нужно заново подтвердить основной профиль» | Пользователь повторно подтверждает именно свой официальный аккаунт. |
| Смена пользователя | «Сменить основной профиль» | Удаляет сохранённый refresh token и запускает новый защищённый OAuth-поток. |

## Границы безопасности

Ник не является учётными данными и не может быть произвольно подставлен в Java-команду. UUID, access token и ник на каждый запуск обновляются из `complete_refresh()` подтверждённой сессии. Лаунчер не читает токены, cookies или зашифрованные файлы официального Minecraft Launcher, не использует чужие Client ID и не создаёт offline-профили.
